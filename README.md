# Market News

Telegram-бот с ежедневным дайджестом рынков. Текст новости открывается внутри бота. Кнопка на сайт издания появляется после нескольких просмотренных материалов.

## Запуск

1. В BotFather создайте бота и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен в `BOT_TOKEN`.
3. Запустите `start.bat`.

Вручную:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Проверка без Telegram: `python -m unittest tests.test_market_news`

## Команды

- `/start` — три главные новости и меню
- `/digest` и `/today` — дайджест дня
- `/analytics` — раскладка по темам
- `/settings` — язык, час рассылки, часовой пояс
- `/help` — справка

Интерфейс по умолчанию русский, в настройках есть английский. Заголовки приходят на языке источника.

## Откуда новости

BBC Business, CNBC, MarketWatch, OilPrice, CoinDesk. Лента обновляется каждые 20 минут. Рассылка один раз в день в выбранный час: если бот в этот момент был выключен, он ещё успевает отправить её в течение двух часов.

## Plus

В настройках есть необязательный Market News Plus за Telegram Stars: недельная подборка и более длинная раскладка. Обычный дайджест, аналитика и рассылка бесплатные и не зависят от оплаты.
